# Preview Templates

A bare preview fence:

```gjs preview
<template><span>bare</span></template>
```

A preview fence carrying code-block options:

```gjs preview collapsible showLineNumbers title="app/components/thing.gts"
<template><span>with options</span></template>
```

A bare preview-template fence:

```hbs preview-template
<span>hbs bare</span>
```

A preview-template fence carrying code-block options:

```hbs preview-template collapsible
<span>hbs with options</span>
```
